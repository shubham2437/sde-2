Verifying integrity offline (no Disseqt tooling required)
---------------------------------------------------------
1. Open manifest.json and read integrity.bundle_sha256 and the per-file
   SHA-256 values under "files".
2. For any file, recompute its SHA-256 (e.g. "shasum -a 256 <file>") and
   compare it to the value recorded in the manifest.
3. The bundle digest covers every file except manifest.json itself; recompute
   each file's SHA-256 and confirm none has been altered.

Only approved evidence is included. Evidence excluded for staleness (when the
exclude-stale option was chosen at export time) is omitted by design; the
report's evidence summary reports the freshness split.
